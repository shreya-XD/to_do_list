# Simple To-Do List Application
A lightweight and beginner-friendly command-line To-Do List program built in Python.
It allows users to add, view, complete, and delete tasks using a simple menu-driven interface.

## Features
Option	Description
1. Add Tasks	Add a new task to the pending tasks list
2. View Tasks	Display pending and completed tasks
3. Mark Task Completed	Move a task from pending → completed
4. Delete Task	Permanently remove a pending task
5. Exit Program	Stop the application
6. Data Structure

## The program stores tasks using two lists:

tasks = []      # Pending tasks
completed = []  # Completed tasks

## How to Run the Program
1️⃣ Save the script as:
todo.py

2️⃣ Open Terminal / Command Prompt
3️⃣ Run using:
python todo.py

## Program Flow
```bash
Start
  ↓
Display Menu
  ↓
User Chooses Option
  ├── Add Task
  ├── View Tasks
  ├── Mark Completed
  ├── Delete Task
  └── Exit
        ↓
       End
```

## Instructions for Use
1.Add Task

2.Enter a task description when prompted.

3.Empty entries are not accepted.

4.Mark Completed

5.Enter the number of a pending task.

6.Moves task to the completed list.

7.Delete Task

8.Removes a task permanently from pending tasks.
